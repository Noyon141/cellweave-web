# Architecture Decision Records (ADRs)

This directory documents the architectural decision records for `cellweave-web` in accordance with the authoritative *CellWeave Production Master System Design v1.0*.

Baseline architectural decisions include:
- `ADR-001`: AnnData canonical representation
- `ADR-002`: R2 storage
- `ADR-003`: Temporal durable workflows
- `ADR-004`: Modal initial compute provider
- `ADR-005`: Polar billing
- `ADR-006`: Processed data only
- `ADR-007`: Pseudobulk condition DE
- `ADR-008`: No PHI
- `ADR-009`: Separate repositories

Changing any baseline decision is not an implementation refactor; it requires formal architectural review and updating the master system design.
